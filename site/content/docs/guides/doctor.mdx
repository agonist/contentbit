---
title: Content doctor is now check
description: Contentbit 2.0 replaced contentbit doctor with contentbit check.
---

Contentbit 2.0 replaced `contentbit doctor` with `contentbit check`, which
checks the built pages as well as the Markdown. See
[Check a site](/docs/guides/check) for the command, and the
[v2 upgrade notes](/docs/maintainers/v2-upgrade) to move a project.
