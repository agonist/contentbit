---
title: Renderers
description: React, Astro, and plain-Markdown output from the same document.
---

Renderers consume a validated document. The parser and registry know nothing about
React, Astro, or HTML — every renderer is an adapter with a per-block renderer map
you can override. Contentbit should complement your host renderer, not replace it:
use it for block structure, validation, metadata, and link graphs, while your app
keeps owning normal Markdown prose. Three targets ship today: React, Astro, and a
plain-Markdown fallback.

## React

```tsx
import { ContentBlocks } from '@contentbit/react'

<ContentBlocks
  document={result.document}
  components={{ comparison: MyComparison }} // override any default
  renderMarkdown={(md) => <Markdown source={md} />}
  fallback={MyInvalidBlock}
/>
```

The headless defaults cover every generic block with accessible semantics: tabs use
`tablist`/`tab`/`tabpanel` with keyboard-reachable buttons, FAQs use native
`<details>`. Interactivity is opt-in per block — only `tabs` carries client state.

For styled components, install the shadcn pack instead of writing your own:

```bash
pnpm dlx shadcn@latest add @contentbit/generic-pack
```

## Astro

```astro
---
import { ContentBlocks } from '@contentbit/astro/components'
import QuoteBlock from '../blocks/QuoteBlock.astro'
---

<ContentBlocks
  document={result.document}
  components={{ quote: QuoteBlock }}
  onInvalid="annotated"
/>
```

Per-block overrides are plain `.astro` components: validated props arrive as
component props, nested content via `<slot />`, and the raw AST node as the
reserved `node` prop. Pass `renderMarkdown` when you want Astro/Sätteri or
another site pipeline to render prose. The `onInvalid` default is `annotated`,
which keeps invalid blocks loud during dev. Full guide: [Astro](/docs/guides/astro).

## Plain Markdown fallback

```ts
import { renderToMarkdown } from '@contentbit/core'
import { genericMarkdownRenderers } from '@contentbit/blocks'

const md = renderToMarkdown(result.document, { renderers: genericMarkdownRenderers })
```

Comparisons become Markdown tables, key metrics become bold-value bullets, tabs
become headed sections. Useful for email, exports, search indexing, and any
environment without a component runtime. Blocks without a renderer degrade to their
raw body — information is never lost.
