# Content doctor

## Overview

`contentbit doctor` scans content once and reports validation errors, link
problems, content health suggestions, and SEO contract findings in priority
order. It is the command to run before opening files by hand.

:::callout{type="note" title="CI mode"}
Use `--strict-seo` when required SEO contract warnings should fail the build.
:::
