# Check a site

## Overview

`contentbit check` reads the built pages and the content once and reports
broken links, validation errors, content health suggestions, and SEO contract
findings. It is the command to run before opening files by hand.

:::callout{type="note" title="CI mode"}
Use `--strict-seo` when required SEO contract warnings should fail the build.
:::
