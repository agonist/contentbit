# SEO briefs and contracts

## Overview

`contentbit brief` turns the SEO config into a compact writing contract. The
brief lists required frontmatter, required sections, block expectations, link
targets, and acceptance checks before an agent starts drafting.

:::callout{type="tip" title="Start from the contract"}
Run the brief before writing, then run doctor after editing so the same rules
validate the finished page.
:::
