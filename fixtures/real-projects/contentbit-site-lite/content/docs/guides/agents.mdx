# Agent authoring

## Overview

Agents should inspect the authoring guide, request the SEO brief for planned
pages, edit Markdown with validated blocks, and finish with doctor. That loop
keeps agent-written pages aligned with project contracts.

:::callout{type="tip" title="Stable loop"}
Brief first, write second, doctor third. The loop is small enough to paste into
an agent task and strict enough to catch drift.
:::
